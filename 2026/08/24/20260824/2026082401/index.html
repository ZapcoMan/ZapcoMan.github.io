空气里飘着整个城市的数据：SDR 软件无线电入门——用一百块的"电视棒"打开电磁世界

2026-08-24 #近源渗透#反监控#SDR#RTL-SDR#软件无线电#无线电#信号分析#频谱

你抬头看不见它，但空气里正飘着整座城市的数据：头顶 400 架飞机的坐标、隔壁楼的对讲机语音、汽车遥控器的开锁码、气象卫星传回的云图、每一部手机的入网请求。这些信号穿过你的身体、你的墙壁、你的房间，24 小时不停。绝大多数人一辈子都不知道它们存在——直到花一百块买一根”电视棒”，然后第一次看见频谱图上涌动的信号海。

这一篇是入口。我们不讲攻击，先讲清楚一件事：无线电世界长什么样，以及为什么”听见它”这件事本身，就让监管者头疼了几十年。

一、先认识电磁世界：空气里到底有什么

无线电不是玄学，它是一张覆盖全球的电磁频谱地图。把频率从低到高排开，你会发现人类文明几乎把每一段可用频谱都塞满了业务。

频段 典型业务 说人话
530–1600 kHz AM 中波广播 收音机 AM 档
88–108 MHz FM 广播 收音机 FM 档
118–137 MHz 民航语音（VHF-AM） 塔台、机组通话
137 MHz 附近 NOAA/国产气象卫星 APT 下行 卫星云图直收
152–280 MHz 一带 POCSAG 寻呼 老旧寻呼台仍在播
350–370 MHz 警务/专用集群 公用对讲服务商、部门专网
400–470 MHz 专业对讲机、出租车台 中继台、手台
433/868 MHz ISM 开放频段 车钥匙、气象站、遥控器
470–790 MHz 地面数字电视 有线电视之外的地面波
900/1800 MHz 蜂窝（GSM/3G/4G）下行 手机基站发给手机
1090 MHz 民航 ADS-B 广播 每架飞机主动播报自身坐标
1575 MHz GPS L1 民用 北斗/GPS 导航信号

这张表我只列了普通设备「零门槛能听见」的部分。注意一个规律：频率越低，传播越远，越难被拦住——中波广播能跨省，短波能绕地球，而 2.4GHz 的 Wi-Fi 连堵一堵墙都费劲。这个物理规律决定了后面所有攻防逻辑。

二、SDR 是什么：把收音机从”硬件”变成”软件”

传统收音机是定死的：买了 FM 收音机，就只能听 FM。因为它用固定的硬件电路（本振 + 滤波器）只对某一小段频率工作，这叫「硬件定义无线电」。

SDR——Software Defined Radio，软件定义无线电——换了一种思路：硬件只负责把天线收到的射频信号搬到一个固定的中频并数字化（ADC 采样），剩下所有事——选台、解调、解码、滤波——全部交给软件。

链路大概是：

所以你不需要换硬件就能听任何东西：同一根棒子，今天解调 FM 广播，明天解码 ADS-B 飞机，后天收气象卫星云图——改的是软件，不是设备。这也是它叫「软件定义」的原因。

金句：过去的收音机，是硬件决定你能听什么；SDR，是软件决定你想听什么。

SDR 的另一面是能看见。传统收音机只给你声音，SDR 的频谱图直接把你所在位置的电磁环境「可视化」了——瀑布图上哪一段有信号、信号多强、什么形状，一目了然。这一步对安全行业意义极大：你终于能”看见”周围 1.7GHz 以下所有活动的发射源。

这里值得把”看见”这件事讲透，因为它是后面所有分析的起点：

  • 频谱图（横轴=频率，纵轴=信号强度）：像一张”电磁心电图”，每一根凸起的”峰”就是一个正在发射的信号。FM 广播的峰又宽又高（大功率、常开），汽车钥匙的峰短而窄（偶尔按一下），Wi-Fi 的峰像一片起伏的噪声丘陵。扫一眼频谱图，你就知道这个房间里”谁在说话”。
  • 瀑布图（随时间滚动的频谱图）：横轴频率、纵轴时间、颜色深浅代表强度。它能看出信号的时间模式——某段频率每晚固定时间出现、某个信号每隔几秒跳一下，这些规律性本身就是身份信息。
  • IQ 数据：SDR 输出的原始数据是”同相/正交”两路采样（I/Q），它们共同描述了信号的幅度和相位——有了幅度和相位，软件才能做解调（FM/AM/ASK/FSK…）。这也是为什么”同一根棒子能听任何制式”：解调全在软件里，数据只是数字。

理解这三样，再看后面任何一篇讲攻击的文章，你就知道攻击者”看到”的到底是什么：不是玄学，是频谱图上一个个有规律的峰。

三、一百块的入场券：RTL-SDR 的传奇

2012 年，一个软件无线电社区（osmocom 团队）发现了一件诡异的事：市面上几块钱一根的 DVB-T 数字电视接收棒，用的是 Realtek 的 RTL2832U 解调芯片，而这颗芯片内部其实藏着一个可编程的通用 ADC 和数字下变频器。电视棒本来是拿来看电视的，但社区把它破解成了通用 SDR 接收机——性能虽糙，价格却低到离谱，一夜之间把”软件无线电”从实验室玩具变成了大众玩具。

现在你上淘宝搜「RTL-SDR」，三十到八十块钱就能买到一根，主要规格：

项目 RTL-SDR（RTL2832U + R820T2）
频率范围 约 24 MHz – 1.7 GHz（直采模式下可下探到几百 kHz）
采样 8-bit ADC，带宽最高约 2.4–3.2 MHz
工作模式 仅接收（RX），不能发射
接口 USB 2.0
价格 国内约 30–100 元

这个价位意味着什么？它比一杯奶茶贵不了多少，却覆盖了上表里 80% 的频段。 对安全研究者来说，这是有史以来性价比最高的「环境感知」设备之一。

为什么一颗电视解调芯片能变身 SDR？拆开看就懂了：RTL2832U 内部其实藏着一个 8-bit 高速 ADC（模数转换器）+ 数字下变频器 + USB 控制器——它本来就是”把天线信号变成数字流”的完整链路，只是出厂固件把它固定成了”电视解调”。2012 年 osmocom 团队发现可以通过控制接口把它重配置成通用采样器：天线进来的信号先由 R820T2 调谐器下变频到中频，再由这颗 ADC 数字化，原始 I/Q 数据直接通过 USB 灌进电脑，剩下的全交给软件。换句话说，你买的不是收音机，是一个可编程的”电磁采样器”——电视只是它出厂时预设的一个用途。而高档版本还会用上 0.5PPM 的高精度温补晶振（TCXO），把频率漂移压到极低——别小看这一点，收 ADS-B 这类窄带信号时，频率偏一点点就什么都解不出来。

如果以后想往发射、更高频段走，进阶路线大概是：

设备 频率范围 收发 价格量级
RTL-SDR 24M–1.7G 仅收 百元内
HackRF One 1M–6 GHz 半双工收发 千元级
ADALM-Pluto 325M–3.8 GHz 全双工收发 两千内
LimeSDR 0.1M–3.8 GHz 收发 三千级
USRP 系列 按型号 收发 万元级专业

对入门者我的建议：先一根 RTL-SDR 把「听」这件事玩透，再考虑要不要上发射。会听，是理解一切无线电攻击的前提。

接收机的三个「短板」，决定了它的天花板

RTL-SDR 虽好，但它的三个硬件短板，直接划定了”你能用它做什么、不能做什么”的边界，值得讲清楚：

  1. 只能收，不能发：RTL-SDR 是纯接收机，没有发射通道。这意味着它只能”看”和”听”，不能”说”。要主动发送信号（比如模拟遥控器、发伪基站信号），必须换 HackRF、Pluto 这类带发射能力的设备。这也天然划出了一条法律边界：RTL-SDR 永远只能当”旁观的望远镜”，成不了”动手的武器”。

  2. 8-bit 采样 = 动态范围窄：8 位 ADC 意味着它区分信号强弱的能力有限。同一个频段里，如果一个强信号（比如附近的大功率电台）旁边躲着一个弱信号，弱信号很可能被”淹没”在强信号里解不出来。这就是为什么收”微弱、远距离”的信号时，RTL-SDR 常常力不从心，需要更高位数的专业接收机。

  3. 频率上限 1.7 GHz：1.7 GHz 覆盖了 FM、航空、ADS-B、GPS、大部分 ISM 频段，但够不到 2.4G 的 Wi-Fi/蓝牙、5G 的蜂窝这些”现代高频段”。要监听 Wi-Fi/蓝牙，得换 HackRF 或专门的 BLE 嗅探设备。

这三个短板凑在一起，给入门者一个很实际的提醒：RTL-SDR 是”最好的入门老师”，但不是”万能的接收机”。 它的价值在于”用最低的成本，帮你建立对频谱的直觉”——等你玩透了它，自然知道自己下一步该升级什么设备、为什么升级。

四、软件工具链：从”听广播”到”看飞机”

硬件只是耳朵，软件才是大脑。最常见的开源工具链：

  • SDR#（SDRSharp）：Windows 上最流行的图形化前端，插上棒子就能看频谱、听广播，入门第一站。
  • GQRX：跨平台的同类工具。
  • GNU Radio：图形化信号处理框架，把解调流程像搭积木一样搭出来，进阶必经之路。
  • Universal Radio Hacker（URH）：Python 写的协议逆向分析神器，对未知信号录下来、解调、分析比特流——后面讲遥控器、门禁时它会反复出场。
  • dump1090 / readsb：1090MHz ADS-B 解码器，配合地图就能实时追踪头顶的飞机。
  • RTL433：433/868MHz ISM 频段传感器解码（气象站、胎压监测、遥控插座）。
  • multimon-ng / PDW：POCSAG 寻呼等旧式数字协议解码。

深读 README：SDR 生态的三根”地基梁”。 上面这串工具，绝大多数底层都踩在同几个开源项目上，读它们的 README 等于看 SDR 生态的”地基图”：

  • rtl-sdr（osmocom 社区）：就是 2012 年把电视棒”破解”成 SDR 的那个项目本体。它的 README 写得很直白：核心是一个 librtlsdr 库 + 一组命令行工具——rtl_sdr（把原始 I/Q 采样 dump 到文件）、rtl_tcp（把棒子变成”网络 SDR 服务器”，局域网里共享给多台机器）、rtl_fm（FM 解调）。现在几乎每一个图形化 SDR 前端（SDR#、GQRX…）底层调用的都是这同一套驱动——你买的电视棒、装的软件、看到的频谱，全村的根基就是这一个 GitHub 仓库。
  • Universal Radio Hacker（URH，Johannes Pohl）：Python 写的”协议逆向工作台”，GitHub 12k+ star，论文发在安全顶会 WOOT’18（USENIX 进攻性技术研讨会）。它的 README 把功能说得非常清楚：录制（把空中的原始信号 dump 下来）→ 解调（自动识别调制参数）→ 分析（自动推断协议字段结构）→ 攻击（录制回放、重放注入、状态协议仿真、模糊测试）。一句话：后面讲遥控器复制、门禁回放时，URH 就是”一条龙”的研究平台。它 2026 年 3 月刚被作者归档为只读——项目不再更新，但代码和文档完好，仍是研究无线协议的标准起点。
  • 顺带一提开源世界的”仪式感”：全球最大的黑客大会 DEF CON 专门设有 Hardware Hacking Village（硬件黑客村），2008 年（DC16）建立，2017 年（DC25）办过十周年——爱好者带自己的板子、示波器、SDR 现场焊、现场刷、现场破解，SDR 一直是村里最热闹的话题之一。

把它们串起来，你能合法体验到的经典场景：

场景 频率 工具 体验
FM 广播 88–108 MHz SDR# 听广播，顺便看频谱上每首歌的形状
航空语音 118–137 MHz SDR# 听塔台指挥起降
飞机追踪 1090 MHz dump1090 头顶每架飞机的航班号、高度、速度
气象卫星云图 137 MHz 附近 WXtoIMG/APT 解码 用两块钱的拉杆天线收卫星传真云图
寻呼台 152–280 MHz 一带 multimon-ng 解密态的公共寻呼文本（大多已是噪音）
气象站/遥控器 433/868 MHz RTL433 你家和邻居家的无线传感器数据

这些玩法全部指向同一个结论：开放的频谱一直在广播，只是你过去没有接收机。 技术圈流行一句话：SDR 让普通人第一次意识到，自己活在一个人人都在发射信息的世界里。

深挖：一次真实的”第一次收听”。 把上述工具串起来，你最可能成功的第一站是国际空间站（ISS）——它在 145.800 MHz（FM）定期向地面发射宇航员与地面的通话语音，当空间站从你头顶过境（每次持续几分钟）时，一根几十厘米的拉杆天线 + RTL-SDR + SDR# 就能直接听到太空里的声音，全程零成本。第二站是 ADS-B 飞机追踪：全球民航客机每 0.5 秒主动广播一次自己的位置、高度、速度（1090 MHz，明文），插上棒子打开 dump1090，屏幕上的每一个光点就是一架真实在飞的飞机——没有任何人”授权”你接收它，它自己选择公开广播。这两个例子加起来就是 SDR 精神的最佳注脚：接收不犯法，前提是你听的是”面向所有人”的广播，而不是”只想给某一个人”的通信。

SDR 入门的三层知识结构

把这一节的所有知识点梳理一下，你会发现 SDR 的知识其实是”三层结构”，层层递进，缺一不可：

层次 内容 对应本文 重要性
① 物理层 频率、频段、信号强度、传播规律 第一节（频谱地图） 地基——不懂频率就不懂一切
② 硬件层 RTL-SDR 等接收机的原理、参数、选型 第三节（RTL-SDR） 工具——决定你能”听见”什么
③ 软件层 解调、解码、协议分析 第四节（工具链） 大脑——决定你能”听懂”什么

这三层的关系，用一句话概括：物理层告诉你”那里有什么”，硬件层帮你”把它采下来”，软件层帮你”把它翻译成能懂的信息”。 少了任何一层，SDR 就玩不转——你光有硬件不懂频率，就像有眼睛却不知道往哪看；光懂理论没硬件，就像知道该看哪却没眼睛。

这也是为什么 SDR 特别适合”入门即上手”：三层的门槛都不高。物理层的频谱知识，一张图就能看懂；硬件层，几十块一根棒子；软件层，全是免费开源。对比其他技术方向（比如要学几年的密码学、要搭复杂环境的后端开发），SDR 的”入门 ROI”高得惊人——你花一个周末，就能从”对无线电一无所知”到”亲眼看到头顶飞机的广播信号”。

五、能听 ≠ 能碰：合法接收的边界

写到这里必须划一条线。SDR 是望远镜，不是钥匙孔——你可以对着公共天空看，但不能把它当成偷听别人私聊的工具。简单说三条：

  1. 接收开放的公共广播（广播电台、民航 ADS-B、气象卫星、业余无线电通联等面向公众发射的信号）——合法，这正是 SDR 的主流玩法。
  2. 解调、窃听他人私密通信（蜂窝通话、对讲机通话、加密数据链路）——违法，无论你技术多好。
  3. 发射任何未经许可的无线电信号——一律违法。RTL-SDR 本身不能发射，但有些设备能，别动那个念头。

补充一个知识点：即便只是「接收」，业余无线电频段通联在中国需要《业余无线电台执照》，无照操作是违法的。收公共广播不需要执照，想玩通联就得考证。这和驾照是一个逻辑：不是不让你开，是让你学了规矩再开。

六、暗面：为什么”一根电视棒”让监管者头疼

现在你理解了它的威力，就明白为什么工信部每个月的例行通报里总有「打击’黑广播’’伪基站’」这一项了。SDR 把两件过去只有专业机构能做、成本极高的事，压到了普通人的手边：

第一件：伪基站。 GSM（2G）协议有个著名设计缺陷——手机单向认证网络，网络却几乎不认证手机。于是一台「笔记本电脑 + 发射器 + 天线 + 手机 + 电瓶」就能冒充运营商基站，让附近所有手机主动投奔过来，然后干两件事：抄下你手机的 IMSI（身份标识），再以运营商名义群发诈骗短信。2010 年代到 2020 年代，大量”您的积分即将过期””办理高额信用卡”短信就是这种设备发的，高峰期一台伪基站能覆盖一个小区、一天群发数十万条，还导致用户手机大面积脱网。这是 SDR/无线电生态被严格监管的第一个原因。

第二件：黑广播。 和伪基站并列出现在工信部月度通报里的，是”黑广播”——私自在 FM 广播频段（88-108 MHz）架设大功率发射机，全天滚动播出”保健品””男科医院””赌场广告”等违规内容。它们抢占正规电台的频率资源，靠的是大功率+长期驻留；而把它揪出来的工具之一，恰恰就是 SDR——无线电管理机构用频谱扫描定位黑广播的发射源，普通爱好者扫到”某个 FM 频率全天只播同一段广告”也基本可以断定是黑广播。监管与黑产共用同一套技术，这是无线电世界最典型的镜像。

第三件：监听与干扰。 用 RTL-SDR 做频谱扫描，可以轻易发现周围的对讲机、专网、甚至特种通信的活动频点——这是近源侦察的基本功。再往上，用发射类设备干扰 GPS、抢占频率，破坏公共通信秩序，则是刑法直接盯上的行为。

法律条文就在这里：《刑法》第二百八十八条——扰乱无线电通讯管理秩序罪：擅自设置、使用无线电台（站），或者擅自使用无线电频率，干扰无线电通讯秩序，情节严重的，处三年以下有期徒刑、拘役或者管制，并处或者单处罚金；情节特别严重的，处三年以上七年以下有期徒刑，并处罚金。2018 年”两高”还专门出了司法解释，把”使用伪基站发送诈骗短信”等情形明确为情节严重。工信部官网每月发布打击”黑广播””伪基站”的查处通报，常年不断。

金句：技术本身是中立的，但频谱是公共资源，占用公共资源扰乱公共秩序，法律一定看得见。

最后补一句给”第一次拿起 SDR”的你：别急着去”破解什么”，先学会”听见什么”。 当你第一次在频谱图上看到头顶那架飞机的广播、听到 ISS 掠过时的太空通话，你会真正理解一句话——我们从未脱离电磁世界，我们只是长期对它视而不见。 SDR 的价值，首先在于睁开这双眼睛。

为什么安全从业者都要会一点 SDR

最后说清楚一件事：为什么安全/隐私领域的人，值得花时间学 SDR？

  • 它是”物理层感知”的入口：软件安全看的是代码，网络安全看的是报文，而 SDR 让你看到”代码和报文”之下的那层物理电磁世界。很多攻击（伪基站、门禁回放、无人机劫持、GPS 欺骗）的本质，都发生在这一层——不懂频谱，你就永远只能”听说过这些攻击”，而不能”真正看懂它们”。
  • 它是”环境侦察”的工具：想知道自己周围”有没有可疑的发射源””车里有没有定位器””房间里有没有偷拍的无线设备”，SDR 是最直接、最便宜的环境侦察手段。
  • 它是”从软件到硬件”的桥梁：对很多只在软件层工作的人来说，SDR 是第一次”摸到物理世界”的入口——从这里开始，你会自然地走向硬件安全、RFID、BLE、侧信道这些更深的领域。

所以这一篇既是”SDR 入门”，也是理解后续伪基站、蓝牙、RFID、GPS、无人机等无线电安全话题的”地基”：这些主题，全都建立在”你能用 SDR 看见电磁世界”这个前提之上。 而这一前提的入场券，只需要几十块钱。

这些暗面内容，后面的文章都会展开——伪基站怎么骗过你的手机、IMSI 猫怎么抄你的身份、遥控器怎么被复制。这一篇你只需要记住：它们是同一套物理世界的延伸，SDR 是打开这个世界的门。

七、防御视角：如果你是被监听的人

把视角翻转过来——理解了”空气里全是信号”，也就理解了反侦察：

  • 一个 SDR 爱好者在楼里扫一圈频谱，就能知道谁家有无线摄像头（2.4GHz）、哪层楼有人用对讲机、楼下停的车钥匙在不在发射。反过来，你的车底如果被人塞了一个发射器（GPS 定位器），它 24 小时在发射信号，这正是它的死穴——它必须发射，你就能发现它。
  • 反侦察的基本功之一，就是定期用 SDR 对自家车位、门前、办公室做频谱扫描，找”不该出现的发射源”。这个思路和我们之前讲的隐私反侦察系列一脉相承：监控必须发射信号，发射就有痕迹，有痕迹就能被反制。

这也是值得单独开一篇讲它的原因：无线电不是孤立的知识点，它是物理攻击、近源渗透、反监控的公共地基。

给新手的一周练手清单

如果你刚买了第一根 RTL-SDR，这一份”第一周练手清单”能帮你快速建立手感，按难度递进：

天数 任务 目标 需要工具
Day 1 装 SDR#，插棒子，看 FM 广播频谱 跑通”硬件→软件”链路 RTL-SDR + SDR#
Day 2 听 FM 广播，认识频谱图上的”峰” 建立”看见信号”的直觉 同上
Day 3 收 1090MHz ADS-B，用 dump1090 看飞机 第一次”解码真实数据” 同上 + dump1090
