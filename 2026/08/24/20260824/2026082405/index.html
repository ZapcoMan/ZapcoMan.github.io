你刷的每一张卡，都是一段射频故事：RFID/NFC 门禁卡安全——从 125kHz 到 13.56MHz 的攻防终局

2026-08-24 #RFID#NFC#门禁卡#MIFARE#125kHz#13.56MHz#复制卡#访问控制#物理安全#物联网

你的包里有一张让你进小区、进公司、进停车场的卡——它没有密码、没有按键、没有屏幕，你刷它进门的时候它甚至不亮。但就是这张沉默的塑料片，可能比你的电脑更容易被复制：花几十块买个读卡器，对着它”扫”十秒，再花几块钱买张白卡”烧”进去，一个一模一样的”你”就诞生了。2018 年，MIFARE Classic 门禁卡的破解工具链已经成熟到”小白点几下就能复制”；2026 年，这类技术早已下沉成网店里的”门禁卡复制服务”。

我们从”听”（SDR）到”攻”（卫星、伪基站、蓝牙），这一篇落到最贴近你日常的一道门：RFID/NFC。刷卡的十厘米，就是物理世界与数字世界的最后一段射频距离。

一、射频识别的世界：125kHz 与 13.56MHz 两大家族

RFID（射频识别）是”用无线电波读取数据”的总称，门禁卡只是它的一个分支。按频率分两大门派：

低频 125kHz（ID 卡） 高频 13.56MHz（IC 卡）
典型卡 EM4100 等 MIFARE Classic（S50）、MIFARE Plus/Desfire
存储 只读一串固定 ID 芯片内有存储区、可读写、有加密
读取距离 数厘米 数厘米（NFC 标准场景）
安全性 极低，ID 明文可复制 Classic 有漏洞可破解；Desfire 等较强
常见场景 老旧小区、简易门禁 小区门禁、校园卡、公交卡、门锁

核心认知：ID 卡就是一张”印着号码的纸条”——它只回答”我是谁”，不回答”你能证明你是你吗”。所以复制 ID 卡 = 抄下号码烧进白卡，零技术门槛。IC 卡稍微硬一点，但它强不强，取决于里面是什么芯片、用的什么加密——而最普及的 MIFARE Classic，恰恰是整条链上最著名的软柿子。

二、MIFARE Classic：被逆向 16 年的”老朋友”

MIFARE Classic 是 NXP 1994 年推出的芯片，用一套叫 Crypto1 的私有加密算法保护数据。它有多普及？小区门禁、校园卡、公交卡、图书馆卡、很多写字楼闸机，全用它。而它的故事就是一部”私有加密=迟早被破解”的教科书：

  • 2008 年：德国研究员 Henryk Plötz 和 Karsten Nohl 在 Chaos Communication Congress 公开演示从芯片物理逆向出 Crypto1 算法，并实现卡密钥克隆——从那天起，Classic 的”加密”名存实亡。
  • 2009 年：Nohl 团队又破解了荷兰 OV-chipkaart 公交系统，直接让荷兰政府紧急重发全国公交卡。
  • 2018 年至今：破解工具链（mfoc、mfcuk、MifareOneTool + PN532 读卡器）成熟到”照着教程点几下”就能跑，网上”门禁卡复制”服务更是把整套流程做成了付费傻瓜包。

破解原理一句话：Crypto1 的密钥生成存在可预测的随机性，配合卡片返回的”认证失败响应”，攻击者能在有限次尝试内穷举出扇区密钥（经典场景：一个扇区默认密钥 + 两次认证尝试即可推导，密钥空间实际被压缩到极低）。一旦拿到密钥，卡内的所有数据区随意读写——复制、修改、写白卡、模拟，全开。

2008 年演示之后，社区把这条攻击路线固化成了两个开源工具，从此”破解 MIFARE”不再是逆向专家专属：

  • mfcuk：实现”Darkside（暗黑侧）”攻击——不需要任何已知密钥，仅靠反复制造认证失败、观察卡片的响应随机性，就能从零恢复一个扇区密钥
  • mfoc：实现”嵌套认证攻击（Nested Authentication）”——先用出厂默认密钥撕开一个扇区，再以此为跳板逐扇区递推，最终拿到全卡密钥（Nethemba 团队的首个开源实现）

两者配合一张几十块的 PN532 读卡器，2018 年后”一键脚本”满天飞——这就是”网店门禁卡复制服务”的技术底座。2024 年 11 月还有安全研究者披露：国产 M1 兼容芯片（如复旦微 FM11RF08(S) 系列）存在后门密钥与可预测随机数问题，等于连”破解”都省了，直接读出厂密钥——这个生态已经退化到”有手就行”。

开源项目：从”命令行小工具”到”射频瑞士军刀”。 mfoc/mfcuk 只是读卡链条的一环，真正把整个 RFID 世界收进一个工具的是 Proxmark3——一块开源硬件，README 自称”RFID 领域的瑞士军刀（swiss-army tool of RFID）”。它的能力清单几乎覆盖整张频率表：低频（125kHz）读写 EM4100、HID Prox、Indala、T55xx 等 ID 卡；高频（13.56MHz）处理 MIFARE Classic/Ultralight/DESFire、NTAG、iCLASS 甚至部分银行卡（EMV）协议；还能嗅探（监听卡与读卡器之间的通信、逆向协议）、模拟（把自己伪装成任意标签）、执行 tearoff 等高级测试。社区维护最活跃的分支（RfidResearchGroup 的 Iceman 版）内置大量已知密钥字典与恢复算法——等于把”破解”的搜索空间替你跑完了。一句话：低端到 EM4100、高端到 DESFire，Proxmark3 全部读写模拟——这就是”物理安全测试”的标准配置。

黑客大会上的门禁攻防。 智能门锁/门禁的破解是国内黑客大会的保留节目，GeekPwn（极棒） 几乎年年有：2017 年，百度安全实验室研究员演示无物理接触、无拆解破解果加智能门锁——可远程获取任意网关下所有门锁密码，波及百万用户；2018 年，腾讯安全团队在极棒上海站现场远程打开豪力士、奥哲美、优点三款智能门锁（全程不接触手机、不连 WiFi）。这些展示的共同结论是：“智能”门锁如果只把安全押在”一把锁”上，那它和普通门锁没有本质区别——只是把撬锁换成了发指令。

金句：1994 年设计的”加密”，到今天 2026 年还在大量小区门上服役——这不是技术的胜利，是成本的惯性。

Crypto1 为什么”看似加密、实则裸奔”

很多人会问：MIFARE Classic 不是”有加密”吗？为什么说它”名存实亡”？这里把 Crypto1 的”死因”讲清楚：

  1. 私有算法 = 没有公开审查：Crypto1 是 NXP 的私有加密算法，从不公开设计。密码学界有句铁律——“私有算法”本身就是一个危险信号，因为没人能公开检验它到底有没有漏洞。公开的 AES、RSA 经过了全球密码学家几十年的攻击检验，而私有算法只能”赌没人研究”。

  2. 2008 年被物理逆向：Plötz 和 Nohl 不是”破解了算法”，而是把芯片放在显微镜下，一层层读出了它的电路，反推出了 Crypto1 的完整逻辑。一旦算法被逆向，”私有”就彻底失效——因为”保密”依赖的是”没人知道怎么算”，而现在已经”人人都知道”。

  3. 随机数可预测：Crypto1 的密钥协商过程依赖一个伪随机数发生器（PRNG），而这个 PRNG 的随机性有缺陷——它产生的”随机数”可以预测。攻击者利用这个可预测性，配合卡片返回的认证失败响应，就能在有限次尝试内穷举出扇区密钥。

  4. 默认密钥大量存在：更致命的是，海量厂商出厂时根本没改默认密钥（比如 FFFFFFFFFFFF），攻击者连”破解”都省了，直接用默认密钥就能读写整张卡。

这四点合起来，就是 MIFARE Classic 的完整死因：私有算法被逆向 + 随机数可预测 + 默认密钥泛滥。它告诉我们一个深刻的道理：加密的安全性，永远取决于”算法是否公开、随机数是否真随机、密钥是否真保密”——任何一点失守，前面的努力全部归零。

三、复制链路：从”扫”到”烧”的三步

一套典型的门禁卡复制流程（全部基于公开工具，用于说明原理）：

  1. 读取：PN532 这类 USB 读卡器贴近卡，用 mfoc/mfcuk 等工具扫描，穷举出扇区密钥，导出卡内数据（UID + 数据块）。
  2. 分析：用 MifareOneTool 等工具查看数据结构——门禁系统大多只校验 UID 或某个固定数据块，看懂”哪块是门禁判断依据”就够了。
  3. 写入：把读出的数据写进一张空白 MIFARE 卡（几块钱），或者直接用手机 NFC（见下节）模拟。写完一张，刷卡试试——能开，就是”你的影子”诞生了。

难度评估：ID 卡（125kHz）≈ 零难度，淘宝”复制 ID 卡”工具一搜一大把；MIFARE Classic（13.56MHz 加密卡）≈ 中级，需要工具链和一点耐心，但 2018 年后已不算门槛；MIFARE Plus / Desfire EV2+ 这类新一代卡 ≈ 高难度，用了更强算法和防克隆机制，目前没有公开的通用破解——这也是为什么银行、新门锁、公共交通正在迁移到它们。

一张「卡的安全等级」全景对照表

把上面散落的难度评估，摊成一张完整的对照表，让你对”自己的卡处在哪个安全等级”一目了然：

卡类型 频率 加密 复制难度 常见场景 建议
EM4100 / HID Prox（ID 卡） 125kHz 无（明文 ID） 零（抄号即可） 老旧小区、老停车场 尽快更换
MIFARE Classic（S50） 13.56MHz Crypto1（已破解） 低-中 大量存量门禁、校园卡 换 Plus/Desfire
MIFARE Plus / Desfire EV2 13.56MHz AES/3DES + 防克隆 高（无通用破解） 新门锁、银行、公交 推荐
手机 NFC（eSE 芯片） 13.56MHz 硬件级安全 极高 手机门禁、Apple Pay 推荐

这张表的规律，和前面”卡型演进”一节是呼应的：安全等级，本质上取决于”卡里存的是静态 ID，还是动态加密凭证”。

  • ID 卡存的是固定的卡号——复制就是”抄下这个号码”，毫无门槛；
  • MIFARE Classic 存的是固定数据 + 弱加密——破解了加密就能复制；
  • Plus/Desfire 存的是每次刷卡都不同的动态认证——复制”上一次的凭证”对下一次无效。

所以判断”我的门禁卡安不安全”，最简单的方法不是问”它是不是加密卡”，而是问：“它是不是每次刷卡都用同一个固定凭证？” 是，就不安全；不是，才谈得上安全。

四、手机模拟门禁卡：便利与边界

“手机刷门禁”是 NFC 最常见的民用落地。但能模拟不等于能复制：

  • 能模拟的：大部分非加密 IC 卡和 ID 卡——手机里的”门禁卡”功能直接复制卡号即可（安卓主流品牌、苹果部分场景）。
  • 不能直接模拟的：加密卡。手机没有 MIFARE Classic 密钥存储区（eSE 安全芯片），模拟不了加密数据。所以现实是：要么用第三方写卡器（约百元）把加密卡数据”烧”成非加密副本，要么就放弃模拟。
  • iPhone 的特殊性：iOS 的 NFC 权限封闭，普通用户能模拟的门禁卡场景远少于安卓；加上 Apple Pay 生态，苹果更倾向”让你用钱包里的卡”而不是”复制你的卡”。

手机模拟的安全边界：自己复刻自己的卡（丢卡备用）通常没大问题，但复制他人的卡、批量复制门禁卡倒卖，就是实打实的违法行为了——“模拟”二字不改变”复制他人凭证”的性质。

门禁卡的「演进史」：从”印号码”到”带密钥”

理解了 MIFARE Classic 的教训，再看门禁卡技术的整体演进，会更清楚”该往哪迁”：

代际 代表 安全机制 破解难度 现状
第一代：ID 卡 EM4100 无（只读固定 ID，明文） 零（抄号即可） 老旧小区仍在用
第二代：逻辑加密卡 MIFARE Classic（S50） Crypto1 私有算法 低（已公开破解） 大量存量，正在淘汰
第三代：CPU 卡 MIFARE Plus / Desfire EV2 公开算法（AES/3DES）+ 双向认证 + 防克隆 高（暂无通用破解） 新系统主流
第四代：手机/动态凭证 手机 NFC + 动态码 / 手机门禁 每次动态变化 + 平台鉴权 极高 未来方向

这张表的规律很清晰：门禁卡的安全演进，就是”从静态 ID 走向动态凭证”的过程。

  • ID 卡和 Classic 卡是”静态的”——卡里存的是固定不变的数据，复制 = 拷贝这份固定数据。
  • CPU 卡和手机动态码是”动态的”——每次刷卡都生成不同的认证凭据，复制”上一次的凭证”对下一次无效。

这也是为什么”治本”的方案不是”换更复杂的加密”，而是”换成动态凭证”——静态的东西，永远可以被复制；只有动态的东西，才能让复制失去意义。

五、风险全貌：一张卡能掀起多大浪

风险 具体危害 谁最受伤
门禁卡复制 盗刷进入小区/公司/机房/宿舍 物业、企业、个人
复制卡倒卖 黑产”包进小区”服务、制售假门禁 小区、写字楼
内部人泄露 员工离职带走卡数据，继续进公司 企业物理安全
复合攻击 卡复制 + 社工（冒充同事混入）+ 尾随 高价值企业

物理安全圈有个老说法：门禁卡的”门禁”属性，本质上只是”知道这个数字”——它不验证”这个人是不是真的”。所以复制卡从来不是最终目的，它只是”进入”这一环的工具，后面跟着的可能是偷盗、窃密、甚至是更严重的入侵。这也是为什么真正的要害部门从不只用刷卡，而是”刷卡 + 人脸/指纹/警卫”多层叠加。

“复制卡进门的浪能掀多大”不是假设，近两年就有几起教科书级案例：

  • 新疆轮台县案（2026-03）：一名嫌疑人用手机 NFC 复制了亲兄弟家的门禁卡，先后 10 余次潜入其家中行窃——直到多次失窃才被发现。复制过程没有任何”高科技”，就是手机对着卡刷一下。
  • 南京邻里案：业主郇某的门禁卡被邻居邢某复制，一年内遭遇 5 次入户盗窃、损失上万元——盗窃案从”撬锁”进化成了”刷卡”，连门窗完好无损。
  • 深圳福田实验（2026-02）：媒体在科技园实测证实，RFID 卡近距离可以被便捷设备盗刷，风险真实存在。

这些案子有一个共同特征：作案者没有破解任何”系统”，只是复制了”一张卡”——而整套流程的起点，往往只是”卡离开过你的手几秒钟”。

一个被低估的威胁：远距离「嗅探」刷卡

大多数人对 NFC 的理解是”贴近才安全”（几厘米内才能读），但这里有一个技术细节常被忽略：NFC 的”官方读取距离”是几厘米，但攻击者的”嗅探距离”可以远得多。

原理在于：

  • 读卡器主动”问话”（发射能量场），卡被动”应答”（反射调制信号）——卡片的应答信号虽然弱，但用高增益天线 + 灵敏接收机，可以在比官方距离远得多的地方”偷听”。
  • 关键不在于”能读卡里数据”（那确实要很近），而在于”能抓到你正在刷卡的瞬间”——攻击者只要在刷卡点附近放一个嗅探设备，就能记录下你刷卡时的通信。
  • 配合定向天线，有研究者演示过在几十厘米到一两米外嗅探 NFC/RFID 通信的可行性。

这个威胁的现实意义：

  • 地铁闸机、门禁读卡器、POS 机，都是”固定地点、高频刷卡”的目标——攻击者在旁边放个嗅探器，一天就能抓到大量卡的通信。
  • 虽然加密卡的数据抓到了也未必能直接解（取决于卡的加密强度），但ID 卡、未加密卡、以及”只校验 UID”的门禁系统，抓到的数据就是可以直接复制的。

所以”卡不离身、卡不贴手机”的建议，本质是防的两种东西：一是”被贴近偷读”（近距离），二是”被远距离嗅探”（刷卡瞬间）。前者靠”卡不离开视线”，后者靠”少在公共读卡器刷卡 + 用加密卡”。物理世界的”射频安全”，从来不是”卡在口袋里就万事大吉”。

六、防御指南：物业与企业版

给物业/企业/个人的防御清单：

给物业/企业（最该改的）：

  1. 淘汰 MIFARE Classic / ID 卡：存量系统逐步迁移到 MIFARE Plus / Desfire EV2、CPU 卡或手机+动态码方案。这是唯一治本的方法——加密不可靠，就从卡本身换起。
  2. 加读卡鉴权：启用读卡器与卡之间的双向认证、防重放；不要只校验 UID。
  3. 后台审计：刷卡记录留痕，异常时段（深夜、假期）的开卡记录要能及时告警。
  4. 门禁物理加固：刷卡 + 人脸/指纹/人工核验的多因素，重要区域再加一层。
  5. 员工离离职管理：卡及时注销、数据及时回收，防止”离职后卡还在用”。

给个人：

  1. 卡不贴手机：手机和卡长期放一起，等于把”复制材料”贴身送给偷拍者（NFC 读取距离虽近，但配合特制天线可被远距离嗅探）。
  2. 卡不离视线：门禁卡借给”同事”刷一下，很可能几秒内就被旁边设备复制。别有用心者可以”借卡”之名行”复制”之实。
  3. 留意异常开锁通知：智能门锁/门禁若支持 App 通知，开启它；发现”人在家却提示开门”立即查。
  4. 不买/不用来路不明的复制服务：帮人复制门禁卡、买复制卡，都是给黑产送生意，也把自己送进风险。

个人防御的「性价比」排序

对普通用户，防门禁卡被复制这件事，其实是有”优先级”的，不是每条都要焦虑地做到极致：

优先级 动作 为什么排这个位置
① 最高 把卡换成 Plus/Desfire/手机动态码 治本——从”卡”这个根上解决问题
② 高 卡不离视线、不随意外借 阻断”复制”最现实的途径（借卡=复制）
③ 中 卡不贴手机、用屏蔽卡套 防”近场嗅探”这类被动攻击
④ 低 留意开锁通知 事后发现，属于”兜底”而非”预防”

这个排序的核心逻辑是：“换好卡”是治本，”管好卡”是防主动复制，”屏蔽”是防被动嗅探，”通知”是事后兜底。 对绝大多数人来说，做到 ①② 就已经挡住了 90% 的风险——因为现实里”门禁卡被复制”的绝大多数案例，都源于”卡是弱加密卡 + 卡被借走/离身”这两个因素的叠加，而不是”有人用高科技远距离嗅探你”。

所以别被”射频攻击很玄幻”吓到，也别因为”好像处处是漏洞”而焦虑。把该换的卡换了、把该守的卡守好，门禁卡的安全，其实没那么难。

反思：门禁的「安全感」，错配在哪里

写完这一篇，有一个值得反复咀嚼的结论：门禁卡的安全问题，本质是”安全投入”和”威胁认知”的错配。

  • 物业/企业：花几十万装了一套门禁系统，却让系统跑在”1994 年的加密”上，因为”看起来能用”就满足了——安全预算花在了”看得见的硬件”上，却没花在”看不见的协议”上。
  • 普通用户：以为”刷卡进门很安全”，却不知道自己的卡可能被”几秒钟复制”，因为”复制门禁卡”这个威胁，从来不在大众的认知清单里。
  • 攻击者：不需要攻破门禁系统，只需要”复制一张卡”——用最低的成本，撬动最贵的资产（进入物理空间）。

这三方的错配，导致了一个荒诞的现实：门禁系统是”物理安全”的第一道防线，却常常是”数字安全”的盲区。 大家默认”物理门禁”比”网络防火墙”更可靠，但事实是——一张 MIFARE Classic 卡，比一个没打补丁的服务器更好攻破。

所以真正的教训不是”换张好卡”，而是改变认知：物理安全和数字安全，本质上已经合流。你的门禁卡，就是你物理世界的”密码”——而”密码”如果 30 年不换算法，就一定会被人破解。

七、收束：把这几条射频线索串成一条线

到这里，从 SDR 入门、卫星攻击史、伪基站、蓝牙到门禁卡，其实是一条完整的逻辑线：先学会”听”（SDR 频谱）→ 再看懂”攻”（卫星/伪基站/蓝牙/门禁的漏洞）→ 最后落到”守”（每一篇的防御指南）。物理安全从来没有”一招封神”，它是频谱感知 + 协议理解 + 行为纪律三者的叠加——而这三样，都不需要你成为黑客，只需要你停止想当然。

金句：电磁波看不见，但它的故事一直在广播——听懂它，是保护自己的第一步。

再补一句务实的收束：这张卡的故事，从 1994 年的 Crypto1，一直讲到了你口袋里的手机 NFC。技术的进化没有让”门禁卡”消失，只是让”攻”和”守”的战场，从”撬锁”移到了”射频”。听懂这段射频故事，不是为了恐慌，而是为了下一次刷卡时，知道自己手里拿的，到底是”一把钥匙”，还是”一张任何人都能复印的纸”。

最后补一句务实的：如果你此刻用的还是”刷一下就能进”的老旧门禁卡，不必恐慌——绝大多数”复制卡”的风险，需要攻击者”拿到你的卡”或”靠近你刷卡”。真正该做的，是推动物业升级卡型、自己保管好卡、开启门禁 App 的通知。把风险认知放在心里，把焦虑放回兜里。
