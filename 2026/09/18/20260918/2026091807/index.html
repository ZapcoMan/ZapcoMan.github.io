检索笔记：历届国际黑客大会的无线电议题，以及那些踩在监管边界上的技术

2026-09-18 #卫星安全#SDR#GPS欺骗#DEF CON#Black Hat#无线电监管#TEMPEST#Meshtastic#IMSI捕获#频谱管理

这是一篇检索笔记，不是综述。

起因是我想要一份「历届国际黑客大会上，无线电议题都讲到了什么、哪些技术天然踩在监管边界上」的清单。检索源主要是 rtl-sdr.com 的 DEF CON 议题汇总、DEF CON 官方归档、以及国内安全媒体的报道。下面按年份整理，并附上我自己的分析与监管侧对照。

说明：部分议题的具体内容细节来自二手报道与议题摘要，以议题标题与公开摘要为准；涉及归因与数字的地方，我在文中标注了来源与不确定性。

一、为什么要专门检索这个

无线电是网络安全里唯一一个物理层的攻击面，也是唯一一个受专门法律约束的攻击面。

前一句好理解：你的 Wi-Fi 密码再复杂，也挡不住有人在你家窗外用定向天线听你的钥匙扣信号。

后一句是这篇文章的重点：你在 Web 上做漏洞研究，主要受授权边界约束；你在无线电上做研究，除了授权，还受频谱管理法规约束。 频率要不要许可、设备要不要型号核准、能不能发射、发射功率多大——这些都不是「技术问题」，是法律问题。

于是产生了一个很有意思的现象：黑客大会上的无线电议题，天然分成两类——纯粹靠接收的（合法），以及需要发射的（多数违法）。 而最有研究价值的那批，往往恰好在两者的边界上。

二、检索结果：一条从 2019 到 2026 的时间线

DEF CON 27（2019）

《The Ford Hack Raptor Captor》 — Dale Wooden（Wireless Village）

用 RTL-SDR 分析福特钥匙扣的信号特征，再用 HackRF 实施攻击。公开摘要里提到的攻击面包括：

  • 拒绝服务而不干扰：让钥匙扣失效，且不留干扰痕迹
  • 重置滚动码计数
  • 重放：开锁、启动、开后备箱
  • 找出主密码：绕过车门 keypad

议题名字里的「Raptor」指福特 F-150 Raptor。这条研究的意义在于它把「汽车无钥匙进入」从传闻变成了可复现的射频链路分析 + 重放。

《SDR Against Smart TVs》 — Pedro Cabrera Camara

针对智能电视的 HbbTV 标准做攻击：频道注入与 URL 注入，进而导向社工、键盘记录、挖矿等后果。这条链路的特点是——攻击载荷是通过广播信号下发的，用户只是换了个台。

《Antennas for Surveillance》 — Kent Britain（Wireless Village）

天线基础，属于入门向。

DEF CON Safe Mode（2020，线上）

《Whispers Among the Stars》 — James Pavur

这是历届无线电议题里我最想单独拎出来讲的一个：

用约 300 美元的家用卫星电视设备，窃听卫星宽带链路的通信内容——家庭宽带、风电场、油轮、飞机的流量；在某些条件下，甚至可以劫持会话。

三个值得注意的点：

  1. 成本：300 美元的消费级设备。不是实验室设备，是能在电商上买到的东西。
  2. 性质：全程只接收，不发射。 所以从监管角度，它不占用频率、不干扰他人——这正是一类「完全合法但危害巨大」的研究。
  3. 跨境：卫星链路天然跨越国界，而下行信号落到哪里，取决于波束覆盖，不取决于你人在哪。

第三点是这篇文章主题的核心：卫星是研究「监管套利」的最佳样本，因为链路的物理属性决定了它不属于任何单一司法管辖区的地面设施。

《Detecting Fake 4G Base Stations in Real Time》 — Cooper Quintin

实时检测伪基站（IMSI catcher），并开源了检测工具。这类议题的价值在于把「检测」能力下放——攻击者做伪基站的成本在下降，检测能力必须同步下降成本。

DEF CON 29（2021）

《Smart Meters: I’m Hacking Infrastructure and So Should You》 — Hash Salehi

针对 Landis+Gyr GridStream 智能电表与 Oncor 电网的研究。议题标题里的「and So Should You」是个态度声明：关键基础设施的射频链路，应该被更多人拿来研究。

《TEMPEST Radio Station》 — Paz Hameiri

这是我最喜欢的无线电议题之一，因为它完全跳出了「通信」框架：

利用 GPU 内存传输产生的电磁辐射作为侧信道，在 50 英尺外接收，达到 33 kbit/s 的速率、99% 的包接收率。

它揭示的是一件反直觉的事：你不需要发射任何东西，你的设备本身就在广播。 数据处理的过程会产生电磁泄漏，而这个泄漏可以被当作一条通信通道来利用。

从监管角度看，这条议题处于一个完全的空白地带：它不涉及任何发射行为，因此没有任何频谱法规能约束它——因为它根本不是「无线电通信」，它只是「电子设备正常工作时的物理副产品」。

《RF Propagation and Visualization with DragonOS》 — cemaxecuter

用 SPLAT!（20 MHz–20 GHz）与 Signal Server 做射频传播可视化。属于方法论向。

DEF CON 30（2022）

《Biohacking Using SDR》 — J9

研究者吞下一个无线 pH 传感器胶囊（每 12 秒广播一次），然后用 SDR 接收自己的体内数据。议题最后落到了与参议院幕僚讨论医疗设备安全。

这条的意义在于它把一个纯粹的「炫技」变成了政策议题：植入式与吞服式医疗设备的无线链路，其安全性此前几乎无人从安全研究角度审视。

《Tracking Military Ghost Helicopters over Washington DC》 — Andrew Logan

用 ADS-B + ATC 通话 + 众包视觉识别追踪华盛顿上空的军用直升机。这些飞机因「敏感政府任务」豁免而不在公开 ADS-B 数据中显示，但通过多源关联仍可定位。议题提到：96% 的噪音投诉无法归因——因为居民投诉时无法知道是哪架飞机。

《Shadytel》（DEF CON 期间展示）

用约 300 美元的 HackRF 设备，连接已退役的加拿大卫星 Anik F1R，并播放内容、直播大会现场。

必须说清楚的两点：

  1. 该卫星已退役，团队明确表示没有干扰任何在用的卫星。这一点决定了它的性质——不是攻击，是利用「已被弃用的轨道资产」。
  2. 它仍然是一个极强的信号：一颗退役卫星的上行链路，仍然可以被地面上的廉价设备接管。 资产退役了，但它的物理能力没有被回收。

自制 PCB 天线 — Erwin Karincic（入门向）

DEF CON 32（2024）

主舞台有四条无线电议题，密度很高：

  • 《RF Attacks on Aviation’s Defense Against Mid-Air Collisions》：针对空中防撞系统的射频攻击
  • 《Breaking the Beam: Exploiting VSAT Modems from Earth》：从地面攻破 VSAT 调制解调器
  • 《GPS spoofing it’s about time, not just position》：GPS 欺骗——重点在时间，不只是位置
  • 《MoWireless MoProblems: Modular Wireless Survey System & Data Analytics》：模块化无线测绘系统与数据分析

第三条值得单独讲：「不只是位置」这几个字，是 GPS 安全研究的一个关键认知升级。绝大多数人对 GPS 欺骗的想象是「把车导到错误的地方」，但真正的风险是时间同步——金融交易时间戳、电网同步、通信基站授时，全都依赖 GPS 的时间而非位置。位置错了你能发现，时间错了你发现不了。

Wireless Village 同年还有：SDR 入门、合成孔径雷达相关法律、不用无线电发射 RF 信号、Allen 射电望远镜阵列、乌克兰电子战实践分享。

其中「不用无线电发射 RF 信号」这一条，正好是本文主题的注脚——在黑客大会上，人们研究「如何不通过无线电设备产生射频」，动机之一正是绕开对无线电发射设备的监管。

DEF CON 33（2025）

RF Village 里有两场 Meshtastic 议题：

  • 《Meshtastic Under the Microscope: From Chirps to Chat》— Allan Riordan Ball
  • 《Meshtastic Command & Control》

Meshtastic 是基于 LoRa 的开源离网自组网项目。它在安全会议上出现的意义在于：它代表了一类「不依赖任何基础设施」的通信能力，而且工作在免执照的 ISM 频段。

DEF CON 34（2026）

官方训练课 《Applied SDR Hacking: Red Team SIGINT for automotive, aviation and marine targets》 — Jos Wetzels & Wouter Bokslag（Midnight Blue）

课程覆盖汽车、航空、海事三类目标的 SIGINT（信号情报）红队技术。

这条值得注意的点在于：它是一门官方付费训练课，不是一场 Village 演讲。 无线电攻击技术从「社区分享」走到了「标准化课程」，说明这套能力已经足够成熟、可传授、有市场需求。

三、从检索结果里提炼：绕过监管的五条技术路径

把上面这些议题按「它们与监管的关系」重新分类，会得到五条路径。这是本次检索最有价值的产出。

路径一：只接收，不发射 —— 完全合法，但危害不小

代表：Whispers Among the Stars（卫星下行窃听）、TEMPEST Radio Station（电磁侧信道）、Tracking Military Ghost Helicopters（ADS-B 众包）、Biohacking Using SDR（体内传感器）

为什么它能绕过监管：频谱管理法规约束的是发射行为（占频、干扰、功率）。纯接收不占用任何频率资源，因此在绝大多数司法管辖区不构成无线电违法行为。

但边界在哪里：接收本身合法，解密与传播接收内容可能触碰其他法律（通信秘密、窃听、数据保护）。所以「合法接收」不等于「合法使用」。

路径二：用免执照频段做长距离通信 —— 灰色地带

代表：Meshtastic（LoRa，470–510 MHz ISM 频段）

机制：各国都为微功率短距离设备留了免执照频段。以国内为例，依据工信部关于微功率短距离无线电发射设备的相关技术要求，这类设备无需申请无线电频率使用许可、无线电台执照和无线电发射设备型号核准；国内 LoRa 相关设备通常工作在 470–510 MHz 频段。

为什么它在边界上：免执照的前提是微功率、短距离、特定用途。而 LoRa 的实际通信距离可以达到公里级，配合组网可以覆盖一座城市——这在技术上超出了「短距离」的立法假设，但在参数上仍符合「微功率」的规定。

监管难点：立法按「功率 + 频段」定义，而实际能力由「调制方式 + 组网协议」决定。用合规的硬件，跑出立法时没有预见到的能力，是所有免执照频段技术共同的监管难题。

路径三：用非无线电设备产生射频 —— 绕开「发射设备」定义

代表：DEF CON 32 的「不用无线电发射 RF 信号」议题；相关开源项目如 rPiTX（利用树莓派 GPIO 直接产生射频信号，覆盖 5 kHz–1500 MHz，无需任何额外射频硬件，一根导线即可当天线）

机制：无线电管理通常对「无线电发射设备」实施型号核准与准入管理。而如果一个通用计算设备（树莓派、显卡、时钟发生器）通过GPIO 翻转或谐波产生了射频信号，它在定义上不是一个无线电发射设备——它只是一台计算机在做数字输出。

为什么它难管：监管的对象是「设备类别」，而技术绕过了「设备类别」的物理边界。你没法禁止一台计算机输出方波。

必须强调：这类项目的开源页面通常明确标注「用于教育目的」「需合法使用」——是否违法取决于你的使用场景，不取决于工具本身。用它做一个合规的微功率实验，和用它干扰别人的通信，法律后果完全不同。

路径四：打「无主权 / 跨境」目标 —— 利用管辖权的物理边界

代表：Whispers Among the Stars（卫星链路）、Shadytel（退役卫星）、Breaking the Beam（VSAT）、航空防撞系统议题

机制：卫星链路、公海船舶、国际航路的物理位置不隶属于任何单一国家的地面管辖。而上/下行信号的落地覆盖范围，由波束决定，不由国界决定。

结果：同一套接收设备，在 A 国合法，在 B 国可能违法；接收同一颗卫星的信号，在不同国家的法律定性完全不同。

这是最典型的「监管套利」：不是规避某一条具体规则，而是利用规则本身有地域边界，而电磁波没有。

路径五：反过来的一条 —— 干扰与反制设备，是明确违法的

这一条必须写进来，因为它是最容易被误解的：

  • 信号屏蔽器 / 干扰器：美国 FCC 明确禁止干扰器的使用、销售与营销（FCC 执法通告长期有效）；国内同样禁止擅自设置使用无线电干扰设备（曾有多起因私自使用信号屏蔽器被查处的案例报道）。
  • 黑广播 / 伪基站：《中华人民共和国无线电管理条例》第七十条对未经许可擅自使用无线电频率、擅自设置使用无线电台（站）规定了没收设备与违法所得、并处罚款；其中对擅自设台从事诈骗等违法活动的情形，罚款上限可达 50 万元。国家无线电办公室会按阶段通报无线电管理行政执法典型案例。
  • 无人机无线电反制设备：未经许可擅自设置使用，同样属于重点打击对象。

一句话区分：研究接收、研究协议、研究实现——通常在红线内；发射、干扰、压制——通常在红线外。 两者的分界线不是「技术难度」，是「有没有占用或破坏他人的频谱资源」。

五、给合规研究者的一份清单

如果你想做无线电安全研究又不踩线，按重要性排序：

1. 先把「接收」这条路走满。
绝大多数有价值的研究（协议分析、信号逆向、侧信道、流量测绘）都不需要发射。RTL-SDR 这类接收设备就能覆盖 ADS-B、AIS、气象卫星、IoT 上行、车钥匙（接收分析）等大量场景。

2. 需要发射时，先问三个问题。

  • 这个频段要不要许可？（ISM 免执照频段 vs 授权频段）
  • 设备有没有型号核准？
  • 发射会不会影响他人？（功率、占空比、天线方向）

三个问题里任何一个答不上来，就先别发射。

3. 在屏蔽环境里做发射实验。
如果需要验证发射相关的漏洞（重放、欺骗），用射频屏蔽箱 / 同轴直连 / 屏蔽室把信号限制在物理空间内。这是实验室的标准做法，也是最干净合规的做法。

4. 涉及航空、铁路、应急、授时的，一律不碰实频。
这些频段的共同特点是：影响的是人身安全与公共秩序，不是数据。安全带没有「测试环境」。

5. 目标系统要自有或明确授权。
这条和 Web 安全研究一样：你只能测你自己的设备，或者有书面授权的设备。测邻居家的车钥匙不是研究。

6. 成果披露走正常渠道。
向厂商/运营方报送漏洞，公开发布时隐去可被直接复现的关键参数（尤其是涉及发射的部分）。安全社区长期以来的做法是：讲清楚原理与影响，不提供「开箱即用的发射方案」。

六、五条明确的红线

前面讲的都是边界，这一节讲没有争议的部分。以下五条在任何情况下都不要碰：

一、伪基站（IMSI catcher）
搭建伪基站会同时触犯多条法律：擅自设置使用无线电台（站）、干扰公用电信网络、可能构成扰乱无线电通讯管理秩序罪。这不是「研究」，这是犯罪。

二、黑广播
未经许可擅自设置广播电台，同样属于擅自设台，且通常伴随诈骗内容与危害航空导航的风险，是无线电管理机构的重点打击对象。

三、手机信号屏蔽器 / 干扰器
私自使用属于擅自设置使用无线电干扰设备。常见的错误认知是「我只在自己屋里用」——干扰的作用范围不由你的墙决定，而且它可能阻断他人的紧急通信。

四、无人机无线电反制设备
未经许可擅自设置使用，属于重点打击对象。这类设备的危害在于它无差别压制，会同时影响合法用户与导航信号。

五、GPS / 授时信号的欺骗与压制
影响的不只是定位，还有金融时间戳、电网同步、通信基站授时。这条红线的特殊性在于：你可能不知道自己影响了什么。

这五条的共同点是：它们都在主动占用或破坏他人的频谱资源。而前面讲的所有「边界地带」技术，共同点是不主动发射。

所以最简单的判断标准其实是：你有没有往空中主动发射信号？ 有，就先停下来查法规；没有，研究的空间通常很大。

七、检索过程中发现的三件事

第一，议题的重心在从「能不能收/发」转向「收到之后怎么处理」。
早期议题（天线、SDR 入门、传播可视化）解决的是能不能拿到信号；近期议题（Meshtastic C2、模块化无线测绘与数据分析、AI 相关）解决的是拿到之后怎么规模化分析。这说明射频侧的基础能力已经不再是瓶颈。

第二，「接收即可危害」的议题占比在上升。
TEMPEST、卫星下行、ADS-B 众包，这三条都是纯接收就能产生实质影响的。这类研究对研究者最友好（无监管风险），对防御者最棘手（无法用频谱管理手段应对）。

第三，无线电正在和 AI 汇合。
DEF CON 34 的训练课把 SIGINT 做成了标准化课程；与此同时，AI 在信号识别、调制分类、频谱感知上的应用正在快速普及。两者结合的后果是：信号分析的人力门槛会像代码审计一样被抹平——这正好呼应了今天写的 10 台云主机 + 一个大模型 = 180 万款 App 的密钥被扒光 里那条主线：瓶颈从技术能力转向算力。

八、一句话总结

这次检索最大的收获，不是某个具体议题，而是一条很清楚的分界：

频谱法规管的是「发射」，而射频安全的风险有一大半在「接收」。

于是出现了一个结构性错位——监管的抓手和风险的来源不在同一个地方。研究者可以完全合法地接收卫星下行、车体泄漏、体内传感器；监管对此无从下手，因为没有任何频率被占用。

反过来说，这也解释了为什么「黑广播、伪基站、屏蔽器」会被严厉打击：它们恰恰是少数几个监管能抓得住的行为，因为它们又发射、又干扰、又明确违法。

如果你要做无线电研究，最实用的一句话是：把研究重心放在「接收 + 分析」上，那里的空间比你想的大得多，而且几乎不需要和法律打交道。

附：入门设备与合法起手式

这一节是给想动手的人的。我的检索里反复出现的三类工具：

① 接收类（低成本、无监管风险）
RTL-SDR 类的软件无线电接收器，配合开源软件就能覆盖大量场景：航空 ADS-B、船舶 AIS、气象卫星下行、IoT 上行信号、车钥匙（接收分析）、FM/数字广播。

② 分析类
信号分析软件（频谱、瀑布图、解调）、射频传播可视化工具（如 SPLAT!、Signal Server 类）、协议逆向工具。DEF CON 29 那场《RF Propagation and Visualization with DragonOS》讲的就是这一类。

③ 发射类（谨慎）
HackRF 一类支持发射的设备。注意：设备能发射，不代表你可以发射。 需要发射的实验，优先放进屏蔽环境或用同轴直连。

三个适合新手的合法练手方向

  1. 接收气象卫星下行（NOAA APT / Meteor LRPT 一类）：信号公开、无加密、完全合法，能完整练习天线、多普勒、解调、图像还原全流程。
  2. ADS-B 接收与自建数据源：接收 aircraft 广播的位置信息，练习协议解析与数据关联。
  3. 自家设备的信号分析：用 SDR 看你自己的车钥匙、门铃、温湿度计的上行信号——测自己的设备，是最干净的合规边界。

这三条的共同点是：只接收、目标公开或自有、不干扰任何人。 在这个范围内，能学到的东西比大多数人想象的多得多。
